# Project Screenshots

This folder contains screenshots for the portfolio projects.

## Required Files

Place your project screenshots in this folder with the following names:

1. **scrollobserver.png** - Screenshot of the ScrollObserver npm package
2. **tachyon.png** - Screenshot of the Tachyon/1E project
3. **retail-travel.png** - Screenshot representing Enterprise Retail & Travel work
4. **nhs.png** - Screenshot of NHS Digital Solutions

## Image Specifications

- **Format**: PNG (preferred) or JPG
- **Aspect Ratio**: 16:9 (recommended for best display)
- **Recommended Dimensions**: 1200px × 675px minimum
- **File Size**: Optimize for web (< 500KB per image recommended)

## Tips

- Use high-quality screenshots showing the UI/application
- Ensure images are clear and representative of the work
- Consider adding subtle branding or watermarks if needed
- For proprietary work, use sanitized or publicly available screenshots

## Fallback Behavior

If an image is not found, the portfolio will display a placeholder with an icon. However, for the best presentation, all screenshots should be provided.
